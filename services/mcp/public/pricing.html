Ograničenja zahtjeva

Domovina MCP poslužitelj je javno dostupan kao MVP — bez registracije računa, bez plaćanja. Ograničenja korištenja primjenjuju se po OAuth klijentu da bi servis ostao stabilan za sve korisnike.

MVP — besplatno za sve. Trenutno ne postoje plaćeni planovi i nije potrebna registracija računa. Limiti opisani ispod postavljeni su konzervativno; ako naletite na njih, javite se i prilagodit ćemo ih.

Aktivna ograničenja

Sliding window po OAuth client_id-u (Claude.ai i Claude Desktop automatski dobivaju vlastiti client_id kroz DCR registraciju). Counters resetiraju kontinuirano dok zahtjevi izlaze iz prozora.

MVP (svi klijenti) 60 1000

Kad probijete prozor, poslužitelj vraća HTTP 429 Too Many Requests s headerima Retry-After, X-RateLimit-Limit-Minute i X-RateLimit-Remaining-Minute (te ekvivalentima za satni prozor). Većina MCP klijenata automatski poštuje Retry-After.

Što se računa

Jedan zahtjev jednak je jednom HTTP requestu prema /mcp (inicijalizacija sesije, poziv alata, ili keep-alive). Sljedeće operacije ne računaju se u kvotu:

  • GET /health — javna provjera dostupnosti
  • GET /.well-known/* — OAuth otkrivanje metapodataka
  • POST /register, GET /authorize, POST /token — OAuth tok (jednom po klijentu)

Status alata u sesiji (lista alata, capabilities handshake) također ne troši kvotu — ona se primjenjuje samo na produktivne pozive alata.
