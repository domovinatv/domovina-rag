Podcast MCP poslužitelj

Model Context Protocol poslužitelj za semantičko pretraživanje hrvatskog katoličkog i političkog podcast korpusa. Spaja se na Claude.ai i Claude Desktop kao prilagođeni konektor.

na mreži

Što je ovo

Javni MCP poslužitelj koji nudi alat search_podcasts nad vektorskim spremnikom (ClickHouse) hrvatskih katoličkih i političkih podcasta. Korpus je prikupljen i transkribiran u sestrinskom repozitoriju fetch.domovina.tv (NVIDIA Canary ASR i pyannote dijarizacija) te vektoriziran modelom bge-m3 (1024 dimenzije).

Spajanje (Claude.ai i Claude Desktop)

U Claude.ai otvorite Profil → Custom Integrations i dodajte vlastiti MCP poslužitelj:

URL: https://mcp.domovina.ai
Autorizacija: OAuth (automatsko otkrivanje preko .well-known)

Poslužitelj podržava dinamičku registraciju klijenta (DCR, RFC 7591) — klijent se sam registrira i prolazi kroz tok autorizacije s automatskim odobrenjem. Nije potrebno ručno postavljanje Bearer ključa.

Krajnje točke

  • POST /MCP zahtjevi (Streamable HTTP)
  • GET /healthprovjera dostupnosti (javno)
  • GET /.well-known/oauth-authorization-serverOAuth metapodaci
  • GET /.well-known/oauth-protected-resourcemetapodaci resursa
  • POST /registerOAuth dinamička registracija klijenta
  • GET /authorizeOAuth autorizacija (automatsko odobrenje)
  • POST /tokenrazmjena OAuth tokena
