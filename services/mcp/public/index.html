Domovina Podcast MCP

Model Context Protocol server za semantic search hrvatskog podcast korpusa

● online

Što je ovo

Javni MCP endpoint koji eksponira search_podcasts tool nad ClickHouse vector store-om hrvatskih katoličkih i političkih podcast-a. Korpus je preuzet i transkribiran u sibling repo-u fetch.domovina.tv (NVIDIA Canary ASR + pyannote dijarizacija), embedovan s bge-m3 (1024-d).

Spajanje (Claude.ai / Desktop Custom Connector)

U Claude.ai Profile → Custom Integrations dodaj custom MCP server:

URL: https://mcp.domovina.ai
Auth: OAuth (auto-discover preko .well-known)

Server podržava Dynamic Client Registration (DCR, RFC 7591) — klijent se automatski registrira i prolazi auto-approve authorization flow. Bez ručnog setup-a Bearer ključa.

Endpoint-i

  • POST / — MCP requests (Streamable HTTP)
  • GET /health — health check (public)
  • GET /.well-known/oauth-authorization-server — OAuth metadata
  • GET /.well-known/oauth-protected-resource — resource metadata
  • POST /register — OAuth Dynamic Client Registration
  • GET /authorize — OAuth authorization (auto-approve)
  • POST /token — OAuth token exchange
