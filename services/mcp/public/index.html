Zašto Domovina Podcast MCP?

Model Context Protocol (MCP) standardizirani je način na koji AI alati pristupaju vanjskim izvorima znanja. Povezivanjem AI alata (poput Claudea ili ChatGPT-a) s Domovina MCP poslužiteljem proširujete njihove mogućnosti istim transkriptima i vektorskim spremnikom koji napajaju pretraživanje na platformi DOMOVINA.ai.

Korpus je prikupljen i transkribiran u sestrinskom repozitoriju fetch.domovina.tv (NVIDIA Canary ASR i pyannote dijarizacija) te vektoriziran modelom bge-m3 (1024 dimenzije) u ClickHouse spremniku.

Kako početi

Daljinski MCP poslužitelj dostupan je na:

https://mcp.domovina.ai

Trenutno je dostupan jedan alat za pretraživanje korpusa — popis alata.

Autentifikacija

Većina MCP klijenata podržava OAuth konfiguraciju. U klijent dodajte ovu postavku:

{
  "mcpServers": {
    "domovina": {
      "url": "https://mcp.domovina.ai"
    }
  }
}

Pri prvom spajanju klijent prolazi kroz dinamičku registraciju (DCR, RFC 7591) i automatski odobreni OAuth tok:

  1. Klijent se automatski registrira preko POST /register
  2. Otvara se URL GET /authorize — odobrenje je automatsko, bez potvrde korisnika
  3. Klijent razmjenjuje autorizacijski kod za Bearer token na POST /token

Nakon autentifikacije svi alati postaju dostupni u klijentu. Nije potrebno ručno postavljanje ključa.

Claude.ai

U sučelju otvorite Profil → Custom Integrations, dodajte „Domovina Podcast" i kao URL upišite https://mcp.domovina.ai. Pri prvom pozivu alata pokrenut će se OAuth tok automatski.

Claude Desktop

U claude_desktop_config.json dodajte gornju mcpServers postavku. Claude Desktop će sam pokrenuti npx mcp-remote proxy i prolaziti kroz OAuth.

Dostupnost

Servis je javno dostupan kao MVP — bez registracije računa, bez plaćanja. Ograničenja korištenja po klijentu opisana su na stranici Ograničenja zahtjeva.
